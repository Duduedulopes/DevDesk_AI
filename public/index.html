O Motor

Rede neural escrita do zero, em NumPy

Nenhum framework de IA, nenhum modelo baixado da internet. Camada, ativação, custo e retropropagação são código próprio — cabem no projeto e são auditáveis.

# o aprendizado: derivar o erro e espalhar
camada → sigmoid / softmax → custo
gradiente = retropropagação

# o gradiente é conferido contra a derivada numérica
O gradiente calculado é verificado a cada mudança contra a derivada numérica — se a prova reprovar, a rede não anda. É o método do projeto: nada confiado, tudo medido.
O Custo

Entropia cruzada categórica

A par obrigatória da softmax. Ela mede o quanto as probabilidades da rede distam da resposta certa — e a penalidade por errar com certeza absoluta é alta.

C = −Σ yi · ln(ai)
a = 0,99 → C = 0,01 # quase nenhum custo
a = 0,50 → C = 0,69
a = 0,01 → C = 4,61 # caro
a → 0 → C → ∞ # nunca dar prob. zero
Errar com certeza absoluta custa infinito — por isso a rede nunca aprende a dar probabilidade zero. Com a softmax na saída, o custo vira o log da probabilidade que a rede deu para a classe certa.
O Texto

Trigramas + contexto

Frase torta ou com erro de digitação ainda alcança a intenção certa. O texto vira peças de letras e o significado emerge de uma janela de contexto.

normalizar → trigramas → peças
"faturmento" → fat · atu · tur · urm · rme …
# ainda alcança "faturamento"
ctx 4 · ctx 8 · ctx 12 · ctx 16 → pesagens
A robustez ao erro veio de trigramas de letras, não de palavras exatas. Os modelos linguagem_ctx* variam a janela de contexto, e cada um é medido antes de entrar.
A Confiança

Limiar de 0,90 — responda, e mostre os palpites

Abaixo do limiar o assistente não se cala: responde com o melhor palpite, avisando a dúvida. E ainda mostra os três candidatos — o clique corrige e vira exemplo rotulado.

confiança < 0,90 → responde mesmo assim
  + avisa: "te respondendo com X% de certeza"
  + mostra 3 palpites → você escolhe
  escolha vira exemplo rotulado
# a dúvida vira aviso, não silêncio
